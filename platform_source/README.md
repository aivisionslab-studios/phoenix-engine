# AIVisions Phoenix Aviary Platform

**AIVisionsLab Studio Group — Creative & Tech Solutions**

Hub de chat e gerenciamento de modelos de IA (local + nuvem), companheiro do [Phoenix Engine](../NOVO%20PROJETO%20PHOENIX%203.0) — acessível pelo botão "🖥️ Plataforma" no Mission Control.

Conecta com Ollama, LM Studio e provedores em nuvem (Gemini, OpenAI, Anthropic), com Model Arena de comparação lado a lado, Model Hub de catálogo aberto e calculadora de VRAM/hardware.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
